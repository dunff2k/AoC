# AoC

Adventures through [Advent of Code]("https://adventofcode.com/")</a>.

Blurb from the site:

```
Advent of Code is an Advent calendar of small programming puzzles for a variety of skill levels that can be solved in any programming language you like. 
```

## Puzzle Input
Each user of AoC receives a bespoke puzzle input for each puzzle (that's why there's no data files in this repo). After cloning the repo create a subdirectory `/data` and populate it with your own data files following the naming convention: `dayX.[txt|csv]` for seamless running of the solutions.
