# AoC 2025

[Advent of Code 2025]("https://adventofcode.com/2025")</a>.

12 new puzzles for Advent 2025 covering different fundamental problems.

Each heading links to the solution code.


[Day 1: Secret Entrance](day1.ipynb)

* Circular/modular arithmetic (dial with 0-99 wrapping)
* Simulation (following rotation instructions)
* Counting occurrences

[Day 2: Gift Shop](day2.ipynb)

* Pattern matching (finding numbers with repeated digit sequences)
* Range processing
* Number theory (identifying numbers where digits repeat exactly twice)

[Day 3: Lobby](day3.ipynb)

* Greedy optimization (finding maximum two-digit combination)
* String/digit manipulation
* Array processing

[Day 4: Printing Department](day4.ipynb)

* 2D grid traversal
* Neighbor counting (checking 8 adjacent positions)
* Grid filtering

[Day 5: Cafeteria](day5.ipynb)

* Range operations (inclusive ranges, overlapping ranges)
* Set membership testing
* Interval processing

[Day 6: Trash Compactor](day6.ipynb)

* 2D input parsing (vertical column reading)
* Expression evaluation
* String manipulation

[Day 7: Laboratories](day7.ipynb)

* Grid simulation (beam splitting)
* Recursive propagation
* 2D traversal with state tracking

[Day 8: Playground](day8.ipynb)

* 3D geometry (Euclidean distance in 3D space)
* Graph theory (connected components)
* Union-Find/Disjoint Set Union
* Clustering algorithms

[Day 9: Movie Theatre](day9.ipynb)

* 2D coordinate geometry
* Rectangle area calculation
* Combinatorial optimization (finding maximum rectangle)

[Day 10: Factory](day10.ipynb)
* Linear algebra over GF(2) (XOR/toggle operations)
* System of linear equations
* Boolean satisfiability
* Button pressing optimization

[Day 11: Reactor](day11.ipynb)

* Graph traversal (directed acyclic graph)
* Path counting
* Dynamic programming with memoization
* Topological relationships

[Day 12: Christmas Tree Farm](day12.ipynb)

* 2D bin packing/tiling
* Shape rotation and reflection
* Constraint satisfaction
* Combinatorial arrangement
